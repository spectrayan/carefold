# Carefold web UI audit — reference images (October 2026)

Reference images for the UI/UX issues #165–#185 in spectrayan/carefold. This branch only hosts images; it is not merged into `main`.

- `current/` — screenshots of the current web app (`apps/web` at `6b4201b`), captured locally against a test install with test accounts and canned model replies. Long pages are cropped and images are downscaled/compressed.
- `mockups/` — redesign concepts (person-centred left rail, profile switcher, family and access, library, helpers, chat; light and dark).

All names, people, clinics, dates and amounts in the mockups are **fictional**. The logo is a placeholder until the community brand-mark call in #151 concludes. The mockups are design direction, not final specifications.
