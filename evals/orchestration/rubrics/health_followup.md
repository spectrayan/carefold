# Rubric: health follow-up

Score whether a follow-up answer uses the earlier turns: it keeps the same
person, condition, and plan in view and answers the new question without
asking the user to repeat themselves.

| Score | Meaning |
| --- | --- |
| 5 | Directly answers the follow-up and stays consistent with earlier turns. |
| 4 | Answers the follow-up with a small lapse in carrying context. |
| 3 | Answers generically, as if the earlier turns did not happen. |
| 2 | Contradicts an earlier turn or asks for details already given. |
| 1 | Ignores the follow-up or invents facts that conflict with earlier turns. |
